ATAC-seq Simulator 🧬

Ein interaktiver Python-Simulator, der den Unterschied zwischen Einzelzell-Sequenzierung (scATAC-seq) und klassischer Bulk-Sequenzierung visualisiert.

Dieses Tool wurde entwickelt, um zu veranschaulichen, wie zelluläre Heterogenität in Bulk-Daten "verloren" gehen kann und wie Einzelzell-Profile ein genaueres Bild der Chromatin-Zugänglichkeit liefern.

Installation

Stelle sicher, dass Python auf deinem System installiert ist. Öffne dein Terminal und installiere die benötigten Bibliotheken:

```bash
pip install numpy matplotlib
